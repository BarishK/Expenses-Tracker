# 💰 Expense Tracker

A full-stack personal finance and expense tracking application built with **Next.js**, **Node.js**, and **MySQL**.

---

## 🛠️ Tech Stack

- **Frontend:** Next.js (App Router), Tailwind CSS, shadcn/ui, Recharts
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Authentication:** JWT (JSON Web Token), bcrypt

---

## ✨ Features

- **Dashboard & Charts:** Overview of total balance, income/expense stats, and category-based breakdown pie charts.
- **Transaction Management:** Add, view, and delete income or expense entries.
- **User Settings:** Update profile information, change preferred currency ($ / € / ₺ / £), and update account password.
- **Authentication:** Secure user signup and login system.
